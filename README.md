# Another One Fast or Slow? — решение команды «Team 6 - Турбо»

Решение соревнования Kaggle **Another One Fast or Slow? Predict AI Model Runtime Again**: предсказать время выполнения (`latency`, мс) ONNX-графа на неизвестном ускорителе по строке (файл, batch, shape). Метрика — RMSLE.

## Как воспроизвести

1. **Токен Kaggle.** Получите токен в настройках аккаунта Kaggle и сохраните его в `~/.kaggle/access_token` или передайте через переменную `KAGGLE_API_TOKEN`. Токен в репозиторий не коммитьте.
2. **Данные.** `python3 scripts/fetch_data.py --out data` — скачивает CSV и ONNX-файлы соревнования. Приватные файлы (после выдачи организатором): `python3 scripts/fetch_private.py --out data`.
3. **Окружение.** `uv sync`. На Linux с GPU ставится `onnxruntime-gpu`, на macOS — CPU-версия.
4. **Расчёт.** Конвейер запускается скриптом `scripts/final.sh`:
   - на сервере (через `scripts/remote.sh`, нужен SSH-алиас сервера в `~/.ssh/config`; имя алиаса задаётся переменной `REMOTE` в `scripts/remote.sh` и `scripts/final.sh`);
   - локально: `scripts/final.sh --local --no-measure`.
   Итоговый набор параметров — в `PLAN.md`, раздел 6.
5. **Сабмит.** `scripts/submit.sh submissions/<файл>.csv "сообщение"`. Скрипт сразу отправляет файл на Kaggle, поэтому запускайте его осознанно.

## Что не входит в репозиторий

- `data/` — данные соревнования и закрытого датасета;
- `submissions/` — предсказания по тестовым строкам и журнал сабмитов;
- `.venv/` и кэши Python, `catboost_info/`, `.DS_Store`;
- токены, ключи и адреса серверов.
